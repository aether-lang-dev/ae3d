### Aether 0.822.0

- **`AETHER_REF` v0.822.0.** An extern now belongs to the module that
  declares it (aether#2948), so `tests/test_quoted_hashes.ae` imports
  `ae3d.vkspirv` for the committed hashes. Before, that import handed
  vkspirv's `memcpy` declaration to every module in the program, so the
  build failed with 119 E0200s, and the test read the hashes through
  `vkframe.quoted_hash` instead. That function is gone.
- **A string built in a `return` and passed to a call is no longer leaked
  (#2946).** `nethandover`'s bone name and two of `ae3d.net`'s op answers
  had bound such a string to a local first; they are written inline again.
  On 0.821.0, valgrind finds 3,929 bytes lost in `test_net_handover`; on
  0.822.0 it finds none.
