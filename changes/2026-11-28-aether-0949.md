### Aether 0.949.0

- **`AETHER_REF` v0.946.0 to v0.949.0.** A tracking bump; no new primitive is
  needed and no source changed. 0.948.0 removed `string.to_double_raw`, which
  the loader and four other modules call, so the engine did not build on it;
  0.949.0 restores it. 0.947.0 to 0.949.0 also check `os.which` and
  `os.getcwd` against the sandbox, add `contrib.xmp` and `std.ipc` shared
  buffers, and make `string.to_float` a correctly rounded 64-bit parse; the
  engine uses none of these. The suites tier of `./ci.sh` is the check.
  - No motion code was changed.
