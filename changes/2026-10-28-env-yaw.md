### A yaw for the environment map (#869, Nic 875-6)

- `engine_set_environment_yaw(e, degrees)`, `engine_set_environment_look(e,
  intensity, degrees)` and `AE3D_ENV_YAW=degrees` turn the environment map about
  up, in the sense the camera's yaw turns. It is one float of the
  `env_capture` quote shader (the capture stays 256 texels), so a turn remakes
  the capture and the filters once and does not read the file again;
  `renderer_set_environment_look` on both backends does the same for a renderer
  driven directly. Yaw 0 is the arithmetic it was, so every frame without a yaw
  is byte for byte what it was. Readers: `engine_environment_yaw`,
  `engine_environment_intensity`.
- `tests/fixtures/env/sides.hdr`, a map warm on the +x half and cold on the other,
  for the tests: the CPU run of the capture, a lit cube on both backends
  (`test_environment`), the engine and `AE3D_ENV`/`AE3D_ENV_YAW`
  (`test_scene_look`) and a GL against Vulkan frame (`test_backend_parity`).
