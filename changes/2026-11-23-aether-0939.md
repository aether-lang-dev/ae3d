### Aether 0.939.0

- **`AETHER_REF` v0.936.0 to v0.939.0.** A tracking bump; no new primitive is
  needed and no source changed. 0.939.0 removes `std.http.client`'s
  process-wide connection pool (a request with no pool opens a connection of
  its own); the engine does not use the client, and `tools/drive_editor.ae`
  makes plain `std.http` calls to the editor's local driver, which still
  compile (built on 0.939.0, macOS arm64).
  - No motion code was changed.
