### Depth of field on the Rendering component (#870, Nic 874-6)

- `depth of field`, `dof focus distance`, `dof aperture` and `dof max blur` are
  fields of the scene's Rendering component, next to fxaa, bloom and TAA: the
  Scene panel in the editor, `component.get`/`component.set` over the agent
  channel and a save game carry them with no other change, and the component
  writes only fields that differ from the defaults (off, 10, 12, 16), so every
  earlier save loads with the depth of field off. The upscaler and the render
  scale stay off the component, as DLSS is.
- The scene file's view gains `dof`, `dof_focus`, `dof_aperture` and
  `dof_max_radius` in its `rendering` object, each written only when it differs
  from the default, so a scene that never used it is byte for byte the file it
  was; a file without them loads with the depth of field off. Loading a scene
  sets the depth of field to what the file says (off for an older file), as it
  does the bloom.
