### Menus: hit testing, focus, widgets, a menu stack (#484)

- `ae3d.menu`: buttons, toggles, sliders, text fields and labels laid out
  like the HUD (anchors, points, panels). A stack per engine
  (`engine_menus`): the top menu takes clicks, keys and pad buttons, the
  ones below are drawn dimmed, and Escape or B pops it.
- `ae3d.input`: typed text as code points (GLFW's character callback,
  `inject_text`), and the game's input blocked while a menu is open; the
  block holds for the frame in which the last menu closes. Raw reads for
  the menu.
- The editor's engine runs the same stack, so a game's menu works in its
  viewport.
- `examples/game_hud.ae` has a pause menu. `tests/test_menu.ae` covers
  clicks, focus order, typing and the block at two sizes and two scales,
  and draws the menu on both renderers.
