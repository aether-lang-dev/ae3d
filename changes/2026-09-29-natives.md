### native/ is the platform's C and DLSS's C++, nothing else

- `native/gpu/` is gone (#398). What was left in it moved to Aether:
  - `opengl_api.c`, the OpenGL resolver: `ae3d.glapi` looks an entry
    point up itself -- the process first through the dynamic linker
    (RTLD_DEFAULT: null on glibc, -2 on macOS), then GLFW's resolver, and
    on Windows GLFW's alone -- and on Linux still holds the library a
    pointer lives in open, so a context torn down never leaves the kept
    pointers pointing into unmapped memory;
  - `offscreen.c`, the offscreen context: `ae3d.offscreen` makes it with
    CGL on macOS (no NSApplication taken over) and a hidden GLFW window
    elsewhere, with the same attributes and hints;
  - `jobs.c`, the door the native loops reached the job pool through:
    `ae3d.jobs` installs its runner in `ae3d.geometry` (`set_runner`),
    which runs the crowd's instance matrices over it (`run_blocks`) and,
    with no runner, on the calling thread. A script is a library with its
    own copy of `ae3d.geometry`, and its copy has no runner: its loops run
    on the thread that calls them. (A weak `@c_callback` is not exported
    from a Windows DLL, so handing a script the host's runner would have
    worked on two platforms of three.) The four scripts under
    `resources/scripts` call none of those loops;
  - `stores.c` and `stores.h`, the C view of the mesh and instance stores
    and `tests/test_geometry`'s check that it matched Aether's: no C reads
    the stores any more;
  - `ae3d.h` and `internal.h`, with nothing left to declare; the build no
    longer passes `-Inative`.
- The Vulkan GLSL the generator derives is out of `native/` (it is not
  C): `src/ae3d/vkspirv/glsl`, beside the SPIR-V it compiles to, and
  glslang's intermediates under `build/shaders`.
- `test_backend_parity` gives the same numbers channel for channel. Its
  "clouds over the skybox" count reads 2082 where it reads 2081 in about
  one run in five, in the C frame core as here: the renderers take the
  clouds' time from the wall clock. The 110 suites pass (`test_dlss`
  skips without the SDK), the four scripts build and `test_script`
  passes, `crash.c` and `stub.c` compile alone under
  `-Wall -Wextra -Werror`, and the Linux and macOS branches of the moved
  code compile here with the platform names swapped.
