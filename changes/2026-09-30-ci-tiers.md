### CI runs what each runner is there for (#511)

A pull request push cost about 90 runner-minutes, almost all of it compiling
the engine into some 150 programs on three platforms. Now:

- **A tier per runner** (`AE3D_CI_TIER` in the workflow's matrix):
  - Linux (`full`): every suite, the examples, the editor, the benchmarks'
    smoke run and the Vulkan validation layer.
  - macOS (`leaks`): every suite, each held to `leaks`, several at a time
    instead of one after another.
  - Windows (`platform`): the 24 suites over code that differs by platform
    (sockets, threads, files and formats, float rounding, scripts) instead
    of all 119.
- **The showcase scenes are the local gate's.** The street played and
  wandered, the demo scene measured, critiqued and held to its cost, the
  impostor atlas and renderer parity moved to `scripts/ci_scenes.sh`, which
  `./ci.sh` runs with no tier and a runner runs only with
  `AE3D_CI_SCENES=1`. Their tools are built only when they run.
- **No run for prose.** A pull request that changes only `*.md` (other than
  `docs/agent.md`, which the suite checks) or `changes/` starts nothing.
- **A push cancels the run under way** for the push before it.
- **Aether pinned to a release** (`AETHER_REF`, v0.748.0), so the
  toolchain's cache holds across runs instead of rebuilding for every new
  commit to aether's main.
