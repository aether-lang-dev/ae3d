### Aether 0.931.0

- **`AETHER_REF` v0.860.0 to v0.931.0.** A tracking bump with the rest of the
  family; no new primitive is needed.
  - `ae3d.glapi` declared `TEXTURE_WRAP_R` twice, once as a const and once in
    its exports list. The compiler now refuses a repeated declaration (E0400),
    which stopped every program importing the engine. The second declaration
    of each is removed; the value (32882) is unchanged.
  - All 309 programs under tests, examples and tools, the 144 modules and the
    editor (on aether-ui 58e9fa15 and on its main) pass the compiler's front
    end on 0.931.0 without an error or a warning.
  - No motion code was changed.
