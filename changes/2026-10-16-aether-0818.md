### Aether 0.818.0: the ownership rework

- **A `ptr` parameter a function keeps is declared `@keep`** (E0902): 370
  across `src/`, the editor, the tools and the tests, wherever a function
  stores one in a field, an element, a module `var` or a struct, returns it,
  or hands it to another keeping parameter. aephysics moves to 51c67d7 for
  its own.
- **A function no longer frees a string it was passed** (E0901). A store
  into a string field or a module `var` now releases what it held, so
  `core.set_owned` (and history's and vkdevice's copies of it) are gone: a
  setter is a plain store of a copy. `net.json_text`, `generate_shaders`'
  `at_450` and the inspector's `told` leave the string to its caller.
- **vkdevice's instance extension names**: the window's surface extension
  is a local before it goes into the `string[]` view of C memory, which no
  longer takes a reference of its own.
- `core.preload_images` collects its decoded images in a list, as
  `std.worker.map` does: a completion's `ptr` is borrowed and cannot be
  `@keep`.
- Two strings built inside a `return` are bound first (`nethandover`'s bone
  name, two of `net`'s answers): 0.818.0 leaks such a string when the call
  returns a pointer (the macOS leak check found it in `test_net_handover`;
  reported upstream).
