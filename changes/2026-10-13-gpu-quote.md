### FXAA written with `quote`: ae3d.gpu reads the tree Aether hands it

- **FXAA is written in Aether** (`ae3d.shaders.fxaa`): `fxaa(screen, texel,
  edge, edge_min, subpixel)` returns `fragment("fxaa") quote | uv: vec2 |
  { ... }`, FXAA's body as ordinary Aether (Aether 0.810's `quote`,
  aether#2819). The compiler type-checks it and hands `ae3d.gpu` the tree,
  every node with its type; the function's parameters the body reads are
  the shader's uniforms (the tree's captures), the texture its sampler.
- **`ae3d.shaderlib`** is what a quoted shader is written against: vec2,
  vec3 and vec4 as distinct types over f32x4, `Texture`, and GLSL's builtins
  (texture, dot, min, max, abs, sign, clamp, smoothstep, mix, fract, floor,
  the constructors, and `rgb(c)` for `c.rgb`) declared once as Aether
  functions whose bodies are what each means, so a quote's body also runs as
  plain Aether.
- **`ae3d.gpu` walks a `quote.Tree`** through std.quote; `GpuNode` and the
  hand builders are gone. The GLSL back end takes loops (`while`, `for`,
  `break`, `continue`), an else-if and int uniforms as well as what FXAA
  uses, and refuses a struct literal with the quote's file and line. It
  writes the uniform block's std140 layout (`params_*`) and fills a buffer of
  it from the captures' cells (`params_write`), and the full-screen vertex
  shader a pass draws a shader with (`emit_screen_vertex`). The CPU back end
  reads the captures from their cells as each run begins.
- `tests/test_gpu.ae`: the GLSL (`tests/fixtures/gpu/fxaa.frag`, regenerated:
  the quote's names, `texel`, `edge_min`, ..., and `.rgb` where `rgb()` is
  called) and its vertex shader compile with glslang and pass spirv-val; the
  block is `vec2 texel@0 float edge_min@8 float edge@12 float subpixel@16`,
  32 bytes, and holds the captured values; the evaluator agrees with FXAA
  written in Aether on ae3d.shaderlib's functions on all 96 pixels, worst
  2.4e-8, both paths taken (41 and 55 pixels); a shader with loops, an
  else-if and an int uniform runs on the CPU as its body runs as Aether, for
  k from 0 to 7. A continue taken as a break fails it (worst 1); a
  smoothstep off by a twentieth fails FXAA's (0.0615).
- **The CPU's sampler weighs to 1/256 of a texel**, as a GPU's does: the
  texel is now an f32 vec2, and a coordinate a rounding off a texel's
  centre took a millionth of the next texel in doubles where the GPU reads
  that texel alone. On one pixel of `tests/test_gpu_fxaa.ae`'s frame, whose
  contrast sits on FXAA's threshold, that was the other side of it, five
  steps of 255 out. Quantised, every channel of every pixel is within one
  step of the GPU's again, 6122 of 6144 pixels exactly on an Apple GPU
  (6110 with the hand-built tree).
