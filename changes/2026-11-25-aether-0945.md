### Aether 0.945.0

- **`AETHER_REF` v0.939.0 to v0.945.0.** A tracking bump; no new primitive is
  needed and no source changed. 0.940.0 to 0.945.0 change the HTTP client's
  retry and error wording, the listen backlog, actor message batching (a `for`
  loop sending from outside an actor now batches its sends like `while`; a
  batch from main waits for room in a full channel), account trips under a
  parent account, and make `std.math`'s scalar functions and a slice view's
  release inline (values unchanged); 0.945.0 adds the macOS cross-build fix and
  three merge and typechecker rules (struct literal fields against module
  variables, a glob import binds only exports, a local named like an imported
  function is E0301). The engine uses none of the client,
  `tools/drive_editor.ae`'s plain `std.http` calls to the editor's local driver
  still compile, and nothing here sends from a `for` loop outside an actor and
  asserts on ordering. The suites tier of `./ci.sh` is the check, run on
  ae-x64 (Ubuntu 22.04 x86_64, a 0.945.0 release install).
  - No motion code was changed.
